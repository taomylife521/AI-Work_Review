# Work Review v1.1.1

**Release date**: 2026-08-10

## Added

- Explicit user memories can now be created, edited, deleted, and cleared from a dedicated settings panel.
- Semantic-memory indexing and rebuild flows now guard state transitions, concurrent work, and partial failures.
- `POST /v1/screenshots/capture` captures the active screen immediately and returns JPEG Base64. It requires Localhost API authentication, respects the screenshot privacy switch, and never uploads automatically.
- Daily reports now include a previous-day action for continuous backward navigation.

## Fixed

- Expanding tool steps or answer evidence in older assistant messages no longer forces the conversation to the bottom.
- The assistant again explains which records and time range it may use, through a compact accessible info control.
- Hidden-avatar notifications retain their expanded height and transparent regions no longer intercept clicks (#140).
- Windows browser URL probing now uses same-window caching, single-flight execution, timeouts, and a circuit breaker to bound UI Automation work (#141).
- macOS input monitoring retries after permission is granted, and self-owned overlay windows are excluded from activity capture.
- Restored the Tauri development startup path after the TypeScript migration, including PostCSS loading and Vite dependency scanning.
- Browser and application icons use corrected source selection and HiDPI scaling to reduce blur and distortion.

## Improved

- Frontend source, tests, and Node scripts are now consistently TypeScript on Node.js 22+.
- Date controls, corner radii, assistant typography, and overview text hierarchy are more consistent.
- Release tags must match all five version sources and the current `main` commit. Missing installers, portable packages, signatures, or release assets now fail the workflow.
- Official GitHub Actions use Node 24 based releases, removing Node 20 deprecation warnings.
