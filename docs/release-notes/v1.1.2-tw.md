# Work Review v1.1.2

**發布日期**：2026-08-22

## 新增

- 企業微信智能機器人長連線（#147）：Bot ID + Secret 連到 `wss://openws.work.weixin.qq.com`，無需公網。命令仍為 `/devices`、`/report`、`/generate`。Corp ID HTTP 回調保留為選項。同一機器人同時只能一條長連線。
- 可設定助手逾時（預設 120 秒，30–900）與日報逾時（預設 300 秒，60–1800）。單次助手請求共用絕對截止時間；前端逾時會送出取消。日報逾時會中止後台任務。
- 思考模式與輸出預算依提供商對應（Ollama `think`、Qwen 僅串流 `enable_thinking`、SiliconFlow `chat_template_kwargs`、Claude thinking、Gemini thinkingBudget）。不支援的提供商不送額外欄位。Claude 帶工具時不開 thinking。
- 可選將常用設定同步到 WebDAV（AI、分類、外觀）。最後儲存獲勝。本機埠、視窗位置、開機啟動與匯出目錄不覆蓋。

## 修復

- Windows/Linux 緊湊標題列頂距對齊拖曳層；最大化後顯示還原圖示。
- 思考型模型的 `reasoning_content` 可串流，正文為空時回退；連線測試需有非空輸出。
- 各服務商的 API Key / 端點 / 模型名在切換後仍會保留。
- 社群二維碼改為真正的 PNG，不再是誤用 .png 副檔名的 JPEG。

## 變更

- 企業微信僅在憑證變更時重連；命令處理離開 WebSocket 迴圈，心跳可繼續。
- 助手收束從總逾時預留 5–15 秒，用已有工具結果再問一輪模型。
- Bot `/generate` 跟隨設定中的日報逾時，不再寫死 120 秒。
- 移除未再使用的助手問題細分類與相關死碼。
- 安全稽核不再每週定時執行；unmaintained 類 RustSec 噪音已忽略，unsound/漏洞類仍會追蹤。
