# Work Review v1.1.1

**發布日期**：2026-08-10

## 新增

- 可在設定面板建立、編輯、刪除及清空明確的使用者長期記憶。
- 語意記憶索引與重建流程加入狀態校驗、並行保護及部分失敗復原。
- 新增 `POST /v1/screenshots/capture`，可立即擷取目前活動介面並回傳 JPEG Base64。介面需要 Localhost API 認證、遵守截圖隱私開關，且不會自動上傳。
- 日報頁新增「上一天」操作，可連續向前查看歷史記錄。

## 修復

- 展開舊助手訊息的工具步驟或回答依據時，不再強制跳到對話底部。
- 助手以精簡且可鍵盤操作的資訊入口，重新說明可參考的記錄來源與時間範圍。
- 隱藏桌寵本體時保留通知展開高度，透明區域不再攔截點擊（#140）。
- Windows 瀏覽器網址探測加入同窗快取、單飛、逾時與熔斷，限制 UI Automation 工作量（#141）。
- macOS 輸入監控在授權後自動重試，活動擷取也會排除應用自身的覆蓋層視窗。
- 修復 TypeScript 遷移後的 PostCSS 載入與 Vite 依賴掃描，恢復 Tauri 開發啟動流程。
- 修正瀏覽器與應用圖示來源選擇及 HiDPI 縮放，減少模糊與變形。

## 優化

- 前端原始碼、測試與 Node 腳本統一使用 TypeScript，執行環境統一為 Node.js 22+。
- 日期控制、圓角、助手字體與概覽文字層級更加一致。
- 發布 Tag 必須符合五個版本來源並指向目前 `main`；缺少安裝包、便攜包、簽名或 Release 附件時會直接失敗。
- 官方 GitHub Actions 改用 Node 24 版本，移除 Node 20 棄用警告。
