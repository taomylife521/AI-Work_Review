# 日期导航、圆角与应用图标一致性设计

## 目标

解决日报连续回看不便、全应用圆角尺度混乱，以及时间线浏览器图标丢失和视觉尺寸不一致三个问题，同时保持现有数据语义、主题、界面风格和多语言能力。

## 日期导航

- 在日报顶部日期控制组最左侧增加“上一天”按钮，位置先于“今天”。
- 每次点击都以当前 `selectedDate` 为基准减一天，不跳过没有日报的日期。
- 今天无日报而暂时展示昨日日报时，第一次点击选中昨天；内容可以相同，但回退横幅消失，日期语义变为明确的昨天。
- 日期运算使用本地正午解析的 `YYYY-MM-DD`，避免 UTC 换日偏移，并覆盖月初、年初和闰年。
- 日报异步加载捕获请求日期、语言和缓存键；每个异步边界后检查请求编号，旧请求不得覆盖较新的日期。

## 圆角体系

全应用只保留以下语义尺度：

- `--radius-xs: 4px`：微型色块和细小标记。
- `--radius-sm: 6px`：紧凑按钮、输入框和列表行。
- `--radius-md: 8px`：普通按钮、卡片、菜单和设置导航。
- `--radius-lg: 12px`：模态框、抽屉和应用内部主框架。
- `--radius-full: 999px`：仅用于圆点、开关、头像、进度条和短状态徽标。

普通按钮、日期组、输入框、大型容器不得使用胶囊形。A/B/C 界面风格可以改变颜色、密度、边框和阴影，但不得覆盖基础圆角尺度。设置页中的卡片套卡片改为单层分组、分隔行或无背景区块。

## 应用图标

- 已成功取得的原生 Base64 图标始终优先，只有明确的安装器或无有效图标时才使用兜底。
- 采集、分类和 macOS 图标查询统一识别 `cent`、`cent browser`、`centbrowser`，显示为 `Cent Browser`。
- 原生 PNG 通过 Alpha 边界裁切后等比放入统一安全画布，macOS 与 Windows 共用同一规范化逻辑；升级磁盘与前端缓存版本。
- 时间线列表与详情使用相同的相对安全区和 `object-fit: contain`，有图片时移除分类色双层底板。
- 图片解码或加载失败时退回字母图标，不显示破图。

## 测试与验收

- 日期纯函数覆盖连续回退、跨月、跨年、闰年和不同时区。
- 日报源码测试覆盖按钮顺序、本地化键和最新请求守卫。
- JavaScript 与 Rust 测试覆盖 Cent Browser 名称、原生图标优先级和 Alpha 画布规范化。
- 全局静态测试禁止未批准的大圆角及普通控件胶囊形。
- 运行前端完整测试、Rust 相关测试和生产构建。
- 使用 Playwright 在桌面与移动视口、明暗主题下检查日报、设置和时间线，确认无溢出、遮挡、卡套卡和图标缩放异常。

## 范围边界

- 不改变日报生成、导出、缓存格式或历史数据。
- 不引入新依赖；复用现有 `image`、Svelte、Node test 和 Playwright。
- 不修改用户当前正在进行的语义记忆相关工作。
