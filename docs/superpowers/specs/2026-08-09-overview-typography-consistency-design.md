# 概览页排版一致性设计

## 目标

让“常驻网站”与相邻“应用使用”模块采用同一套文字节奏，消除小字号英文偏散、同一信息行行高不一致和紧凑标题过松的问题。

## 根因

- 网站行是带 `items-center` 的按钮，命中全局紧凑控件规则，名称、来源和时长被压为 `1.15` 行高。
- 分类元信息又单独使用 `1.45`，同一行混用了两套行高。
- “应用使用”对应文字均使用 `1.35`，两个相邻模块没有共享排版规则。
- 全局字体栈优先选择 `SF Pro Display`，不适合以 `11px` 至 `13px` 拉丁文字为主的正文区域。
- `ui-style-c` 只缩小区块标题字号，没有同步收紧行高。

## 设计

- 为网站名称增加 `overview-domain-name` 语义类。
- 网站名称、元信息、来源和时长分别与应用排行对应选择器共享字号、字重、颜色和 `1.35` 行高。
- 保留现有网格、间距、进度条、交互与响应式布局。
- 全局正文使用系统 UI 字体优先，并让 Tailwind `sans` 字体配置保持一致。
- `ui-style-c` 区块标题使用 `1.35` 行高。
- 不为单个网站或单条文案增加特例。

## 验收

- 静态回归测试断言共享选择器、统一行高、系统字体顺序和紧凑标题行高。
- 概览专项测试、视觉样式测试和生产构建通过。
- 浏览器计算样式显示区块标题行高约为 `19.9px`，全局字体不再以 `SF Pro Display` 开头。
